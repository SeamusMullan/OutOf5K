\section{About OutOf5K}

\newthought{OutOf5K} is a desktop application designed to help Counter-Strike 2 players analyze their gameplay, track improvement over time, and learn from professional players. The name refers to the aspiration of becoming one of the top 5,000 players.

\subsection{Vision}

The application aims to provide:

\begin{itemize}
    \item Comprehensive demo file analysis
    \item Detailed statistics and performance tracking
    \item Visual replay and positioning analysis
    \item Comparison with professional players
    \item AI-powered coaching insights (future)
\end{itemize}

\subsection{Target Users}

\outof{} is designed for:

\begin{marginfigure}
    \centering
    % \includegraphics[width=\linewidth]{figures/user-persona}
    \caption{Primary user persona: Competitive CS2 player seeking improvement}
\end{marginfigure}

\begin{itemize}
    \item Competitive CS2 players looking to improve
    \item Teams wanting to review scrims and matches
    \item Coaches analyzing player performance
    \item Content creators reviewing highlights
\end{itemize}
